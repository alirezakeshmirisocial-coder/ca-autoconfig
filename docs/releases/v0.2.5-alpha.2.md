# CA AutoConfig v0.2.5-alpha.2

This alpha adds a fail-closed workload candidate gate. It evaluates one explicitly named GPU profile against one explicitly named reference and refuses to advance evidence containing workload failures, incomplete runs, driver-reset signals, phase mismatch, missing telemetry, unstable clocks, temperature violations, excessive performance loss, or too little efficiency gain.

## What changed

- Added `PowerAdvisor.psm1` with `Test-CAWorkloadCandidate` and `New-CAWorkloadCandidateMarkdown`.
- Added `New-WorkloadCandidateReport.ps1` for privacy-checked JSON exports and a deterministic fixture-only dry run.
- Requires live schema-v3 data, an exact workload and hardware/driver identity, aligned rate/power windows, three unique repetitions per profile, and complete declared sample windows.
- Defaults to at least 90% reference throughput, at least 5% same-window efficiency gain, lower mean board power, and no more than 85°C peak.
- Evaluates candidate clocks only under at least 50% utilization, requires three loaded samples per GPU/run, limits p05-to-p95 spread to 5%, and permits at most 30 MHz above the declared ceiling.
- Rejects any failed/incomplete selected run. Driver/GPU reset, device-loss, or NVIDIA Xid text receives a dedicated `driver-reset-evidence` reason.
- Supports aligned token and generalized work-unit evidence through the same gate.

## Decision boundary

The strongest output is `CanProceedPastWorkloadGate`. A pass does not select or apply a profile and does not bypass the separate idle-power, privilege, explicit-confirmation, or rollback gates. Synthetic evidence always returns `FIXTURE`, never `PASS`.

Read the full [candidate-gate rationale and progression](https://github.com/alirezakeshmirisocial-coder/ca-autoconfig/blob/main/docs/research/SAFE_CANDIDATE_GATES.md).

## Install

Download `CA-AutoConfig-Desktop-v0.2.5-alpha.2-win-x64.zip` and its `.sha256` file, verify the checksum, extract it, and run:

```powershell
.\Install-DesktopApp.ps1
```

The installer preserves a valid existing display selection across upgrades.

## Verification

- 28 Power Curve tests, 12 idle-gate tests, 14 workload-advisor tests, nine Ollama tests, nine llama.cpp tests, and eight ComfyUI tests pass in Windows PowerShell 5.1 and PowerShell 7: 80 deterministic cases per runtime.
- The dry-run report expands deterministic samples in memory, returns `FIXTURE`, performs no hardware access, and contains no machine paths or GPU UUIDs.
- Static tests reject NVIDIA mutation flags, process launch, elevation, and scheduled-task paths from the advisor/report implementation.
- The self-contained desktop smoke test verifies the packaged app and display-preserving installer path.

## Evidence boundary

This release contains no real workload curve, no real idle comparison, no whole-system energy measurement, and no universal GPU limit. It does not complete the privileged apply/reset boundary or rollback proof required before an evidence-backed profile can be offered for application.
