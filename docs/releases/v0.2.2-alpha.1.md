# CA AutoConfig v0.2.2-alpha.1

This alpha adds the first workload adapter for building real, reproducible AI power curves: local Ollama generation measured in the same window as NVIDIA board telemetry.

## What changed

- Added `benchmark/Invoke-OllamaPowerRun.ps1`, which runs one deterministic local `/api/generate` request while sampling the selected GPUs.
- Calculates uncached prompt and generation tokens/second from Ollama's official nanosecond counters instead of scraping console text.
- Reads model quantization from `/api/show` and records a non-sensitive benchmark identifier plus fixed context, output, temperature, and seed settings.
- Keeps profile changes separate: the adapter has no GPU-write, elevation, task-control, or model-pull path.
- Uses loopback by default. A non-loopback endpoint is rejected unless `-AllowRemoteEndpoint` is explicit.
- Omits the raw prompt, generated response, GPU UUIDs, machine/user names, paths, and commands from schema-v1 exports.
- Preserves too-short measurements as `incomplete` and measured HTTP/metric failures as `failed`; neither becomes a candidate result.
- Adds nine deterministic adapter tests, including remote-endpoint rejection, concurrent local fixture telemetry, and failed-request preservation, across Windows PowerShell and PowerShell 7.

## Install

Download `CA-AutoConfig-Desktop-v0.2.2-alpha.1-win-x64.zip` and the matching `.sha256` file, verify the checksum, extract it, and run:

```powershell
.\Install-DesktopApp.ps1
```

The desktop installer remains least privilege and HUD-only. The benchmark lab is included but runs only when invoked explicitly.

## Try the adapter

Install a model in Ollama yourself, then follow [`benchmark/POWER_CURVE_METHOD.md`](../../benchmark/POWER_CURVE_METHOD.md). The adapter intentionally refuses to download a missing model.

## Verification

- The 14 schema/report tests and nine Ollama adapter tests pass in Windows PowerShell and PowerShell 7.
- The adapter integration test uses only a loopback fixture server and fake query-only NVIDIA telemetry.
- The actual maintainer endpoint reports Ollama `0.32.5` with no installed models; its missing-model path was verified without creating an export or changing either GPU.
- Both live RTX 3090 cards remained at the approved 280 W / 1695 MHz after verification.
- Release ZIP: 74,430,549 bytes; SHA-256 `d736793fb44abc9025b958614ea5a1d24cb14f5415ea037aa934001975727d27`.

This remains an unsigned Windows/NVIDIA alpha. No real workload power curve is claimed until a model is installed and the full repeated-run protocol is completed.
