# CA AutoConfig v0.1.0-alpha

This first public alpha is for Windows users running local LLM, diffusion, or other sustained NVIDIA workloads who want a quiet HUD and an honest answer to two questions: **are my limits active, and what is the GPU drawing now?**

## Included

- Compact CPU, RAM, storage, CUDA/SM, VRAM, power, temperature, and clock HUD.
- Red/green verification of the applied GPU-limit profile for the current boot.
- Tiny lock pill, click-through locked mode, drag placement, and `Ctrl+Alt+L` default shortcut.
- Visual monitor selection and locally persisted placement/opacity/shortcut settings.
- Read-only, vendor-range-constrained power starting points.
- Start/stop controls, logon and unlock startup, and a separate elevated GPU-limit helper.

## Try it

Review the scripts, open PowerShell as the intended Windows user, and run:

```powershell
.\Install-SystemOverlay.ps1
.\tests\SystemOverlay.Smoke.Tests.ps1
```

The combined camera/HUD/GPU installation is documented in the README, but new users should begin with the standalone HUD. Applying or resetting GPU limits requires administrator approval.

## Alpha boundaries

This release does not automatically apply advisor values. It never treats a static percentage as a proven optimal limit. Benchmark your real workload, retain a rollback path, and stay inside the GPU's reported supported range. Camera-based presence is experimental RGB matching, not liveness detection or a replacement for Windows Hello.

Please use the hardware-result issue form for sanitized benchmark evidence and Discussions for product direction. Do not include GPU UUIDs, usernames, machine names, personal paths, webhook URLs, or biometric material.
