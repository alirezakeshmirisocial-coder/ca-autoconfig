# CA AutoConfig v0.2.4-alpha.2

This alpha makes the Power Curve more scientifically honest: a throughput rate divided by wattage is called work per Joule only when both values describe the same declared time window.

## What changed

- Added `benchmark/schema-v3.json` with mandatory `powerWindow`, `promptRateWindow`, `generationRateWindow`, and `workRateWindow` provenance.
- Updated every writer to schema-v3 while keeping schema-v1/v2 readable.
- Legacy exports retain their throughput and power values, but exact per-joule fields remain `N/A` because their phase provenance is unknown.
- Ollama now declares end-to-end request power separately from official prompt/generation phase rates.
- llama.cpp now declares measured process-window power separately from official `pp` and `tg` phase rates.
- ComfyUI declares rate and power over the same client window, retaining scoped, aligned work/J.
- The generic recorder declares its supplied rate and sampled power as steady-state; the method makes the user's same-window responsibility explicit.
- Markdown reports keep a rate/window-W index for phase-mismatched evidence and state that it is not tokens/J or an energy recommendation.
- SVG cards label repeated phase-mismatched live evidence **MEASURED / RATE-POWER INDEX**, show **ALIGN PHASES FOR ENERGY CLAIM**, and retain both windows in accessible metadata.
- Added a research note covering runtime semantics, phase-aligned energy literature, current LocalLLaMA demand, and the future idle-power regression gate.

## Install

Download `CA-AutoConfig-Desktop-v0.2.4-alpha.2-win-x64.zip` and its `.sha256` file, verify the checksum, extract it, and run:

```powershell
.\Install-DesktopApp.ps1
```

The installer runs the HUD as the standard user at Logon and SessionUnlock, preserves an attached selected display across upgrades, and does not install the camera experiment or apply GPU settings.

## Verification

- 28 deterministic schema/report/card tests pass in Windows PowerShell 5.1 and PowerShell 7.
- Nine Ollama, nine llama.cpp, and eight ComfyUI adapter tests verify their exported schema-v3 window provenance in both runtimes.
- Aligned fixture SVG output is byte-identical across both PowerShell runtimes.
- A separately rendered phase-mismatch card contains no `tokens/J` label, keeps its warning visible, and passed bounded visual finish review.
- The benchmark fixture suite performs no GPU read or write; adapter integration tests use only fake/local fixtures.

No real workload power curve, whole-system energy measurement, external hardware reproduction, or universal GPU limit is claimed by this release.
