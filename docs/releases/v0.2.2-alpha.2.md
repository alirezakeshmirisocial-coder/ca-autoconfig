# CA AutoConfig v0.2.2-alpha.2

This alpha adds an offline llama.cpp workload adapter for producing privacy-safe, reproducible power-run evidence from the official `llama-bench` JSON format.

## What changed

- Added `benchmark/Invoke-LlamaBenchPowerRun.ps1` for an explicit local `llama-bench.exe` and GGUF file.
- Runs one same-shape warm-up repetition, then a measured process with `--no-warmup` while selected NVIDIA GPUs are sampled.
- Requires exactly one matching prompt-processing (`pp`) row and one text-generation (`tg`) row, complete per-repetition samples, positive finite rates, and a consistent build/backend identity.
- Makes batch, micro-batch, thread, GPU-layer, split, main-GPU, flash-attention, token-count, and repetition settings explicit in the workload fingerprint.
- Records a too-short process as `incomplete` and a child/parse failure as `failed`; neither becomes a candidate result.
- Keeps the workload adapter query-only: no GPU mutation, elevation, scheduled-task control, network request, or model/tool download.
- Omits the GGUF path, raw command, child stdout/stderr, and llama-bench `model_filename`, `cpu_info`, and `gpu_info` fields from schema-v1 exports.
- Adds nine deterministic tests across Windows PowerShell and PowerShell 7, including concurrent telemetry, immediate/delayed failures, and private-field omission.
- Includes workload `name` in report comparability, preventing unlike prompt/token/batch/context protocols from producing a false efficiency winner.

## Install

Download `CA-AutoConfig-Desktop-v0.2.2-alpha.2-win-x64.zip` and its `.sha256` file, verify the checksum, extract it, and run:

```powershell
.\Install-DesktopApp.ps1
```

The installer remains least privilege and HUD-only. Both workload adapters are optional scripts and run only when invoked explicitly.

## Try the adapter

Provide your own local llama.cpp build and GGUF model, then follow [`benchmark/POWER_CURVE_METHOD.md`](../../benchmark/POWER_CURVE_METHOD.md). The adapter intentionally contains no download path.

## Verification

- The 15 schema/report tests, nine Ollama tests, and nine llama-bench tests pass in Windows PowerShell and PowerShell 7.
- The llama-bench integration fixture uses only a temporary local executable and fake query-only NVIDIA telemetry; it contacts no service and loads no model.
- Both live RTX 3090 cards remained at the approved 280 W / 1695 MHz after verification.
- `llama-bench` is not installed on the maintainer PATH, so this release does not claim a real GGUF result or power curve.
- Release ZIP: 74,441,575 bytes; SHA-256 `0a8bcf6333b7a60e55c831d08ced8a00893a9eff6d89f3cf5c1222eb574f512d`.

The power samples cover the measured child-process lifetime, including model load and shutdown. Official llama-bench throughput excludes tokenization and sampling. The method documents this distinction instead of treating the two windows as identical.
