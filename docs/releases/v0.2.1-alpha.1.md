# CA AutoConfig v0.2.1-alpha.1

This alpha turns the compiled HUD into a reproducible, privacy-checked power-measurement toolkit without making GPU tuning automatic.

## Highlights

- Added the read-only power-curve lab: schema-v1 anonymized JSON, query-only NVIDIA sampling, explicit missing values, and Markdown comparison reports.
- Added synthetic dual-RTX-3090 fixtures and 14 deterministic calculation/privacy tests that pass in Windows PowerShell 5.1 and PowerShell 7.
- Added calibration-first predictive thermal simulation with chronological held-out validation, bounded interpolation, drift invalidation, and 52 hardware-independent tests. It remains advice-only; `CanApply` is always `false`.
- Added a privacy-safe animated HUD demo and a detailed architecture/trust-boundary document.
- Preserved standard-user read/run control of the protected SYSTEM GPU task without granting permission to rewrite its action.

## Install the HUD

Download `CA-AutoConfig-Desktop-v0.2.1-alpha.1-win-x64.zip` and the matching `.sha256` file, verify the checksum, extract it, and run:

```powershell
.\Install-DesktopApp.ps1
```

The default installer remains least privilege: it installs the HUD only and does not request administrator rights, install the camera experiment, or apply GPU limits.

## Try the power-curve pipeline

The ZIP now includes the benchmark lab. Its built-in dry run uses synthetic data and makes no hardware calls:

```powershell
.\benchmark\New-PowerCurveReport.ps1 -DryRun -OutputPath .\fixture-power-curve.md
.\benchmark\Run-Tests.ps1
```

See [`benchmark/POWER_CURVE_METHOD.md`](../../benchmark/POWER_CURVE_METHOD.md) before recording real data. The lab never sets power, clocks, voltage, or fans. No real throughput claim is included in this release.

## Verification

- All existing guard, HUD, compiled-app, privileged-helper, and 52 cooling/prediction tests pass.
- The 14 new benchmark tests pass in both supported PowerShell runtimes.
- A live two-GPU plumbing check recorded both active 280 W caps, two samples per GPU, no UUID field, and no efficiency leader without throughput.
- The packaged self-contained executable passes headless schema-v1 smoke testing with `hardwareWrites: false`.
- Release ZIP: 74,421,145 bytes; SHA-256 `dbd50b2f30f688407ce0717a3b4dbc11fbd47e7d599b227cb1bbedec1c5b6b6b`.

This remains an unsigned Windows/NVIDIA alpha. Hardware results vary by exact board, VBIOS, driver, cooling, model, quantization, context, batching, and workload phase. Clean-machine reports are still needed.
