# CA AutoConfig v0.2.0-alpha.1

This is the first compiled desktop preview of the CA AutoConfig HUD.

## Highlights

- Self-contained .NET 8 `win-x64` executable; no separate runtime or PowerShell source compilation is required on the target PC.
- Existing tiny lock pill, click-through HUD, visual monitor picker, configurable shortcut, opacity, position, tray controls, GPU profile health, and system/GPU telemetry.
- Schema-v1 settings shared with the PowerShell-hosted alpha. Legacy unversioned settings migrate in memory, while a newer schema is never overwritten.
- Least-privilege scheduled task starts the app at Logon and SessionUnlock.
- Headless smoke mode verifies startup and settings persistence without changing GPU settings.

## Install

Download the `CA-AutoConfig-Desktop-v0.2.0-alpha.1-win-x64.zip` and matching `.sha256` asset, verify the checksum, extract it, and run:

```powershell
.\Install-DesktopApp.ps1
```

The installer does not request administrator rights, install camera monitoring, or apply GPU limits. See [the desktop-preview guide](../DESKTOP_PREVIEW.md) and the repository security/privacy documents before testing.

## Verified on the maintainer system

- Windows 10 `win-x64`, mixed-DPI multi-monitor layout.
- Framework-dependent and self-contained builds completed with .NET SDK 8.0.425.
- Self-contained executable remained running, created its settings IPC event, and launched from the existing `CA System Overlay` task at `Limited` privilege.
- The extracted release-package candidate passed schema-v1 smoke testing with `hardwareWrites: false`.

This remains an alpha. The binary is not code-signed, Windows/NVIDIA are the only supported public platform/provider, and clean-machine coverage from external testers is still needed.
