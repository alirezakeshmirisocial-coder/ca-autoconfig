# CA AutoConfig v0.2.1-alpha.3

This alpha makes GPU identity stable across driver or reboot index reordering and repairs the user-facing apply path.

## What changed

- GPU indices now select cards only during installation. The installer resolves stable NVIDIA `GPU-...` UUIDs before elevation and pins the protected scheduled task to them.
- Applied state includes UUIDs, and the HUD verifies live cards by UUID rather than trusting a mutable numeric index.
- Reset reads and preflights the applied profile instead of assuming GPUs `0,1`; missing or invalid state fails closed.
- Control-panel status compares live values with each applied profile instead of assuming a maintainer-specific `280 W` target.
- Existing index-only state remains supported for upgrades.
- The control panel runs the exact reviewed GPU task and waits for a fresh state result. HUD-only installs no longer fail when the optional camera task is absent.
- Thirteen deterministic NVIDIA cases include simulated index reordering, a different card occupying an old index, malformed profile identity, and duplicate profile identity.
- Product version is `0.2.1-alpha.3`, assembly version is `0.2.1.0`, and file version is `0.2.1.3`.

## Install

Download `CA-AutoConfig-Desktop-v0.2.1-alpha.3-win-x64.zip` and the matching `.sha256` file, verify the checksum, extract it, and run:

```powershell
.\Install-DesktopApp.ps1
```

The desktop installer remains least privilege and HUD-only by default. GPU mutation is a separate explicit workflow requiring target indices, MHz, watts, risk acknowledgement, and UAC.

## Verification

- Guard, HUD, compiled-app, privileged-helper, benchmark, and all 52 cooling/prediction tests pass.
- The deterministic HUD suite covers 13 NVIDIA identity, state, and telemetry cases; hardware-writing fixture paths remain absent.
- The live maintainer task is UUID-pinned and can be started by the configured standard user without task-write permission.
- Both configured RTX 3090 cards remain at the approved 280 W / 1695 MHz after migration.
- Release ZIP: 74,420,349 bytes; SHA-256 `0fb7492e9374fe035ba7c4cb5ad32f3b32c511fd64de482aab889f91f452ba31`.

This remains an unsigned Windows/NVIDIA alpha. The benchmark fixtures are synthetic and no universal power limit is claimed.
