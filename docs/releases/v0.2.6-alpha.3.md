# CA AutoConfig v0.2.6-alpha.3

This alpha adds an offline verifier for the Windows desktop bundle. It does not change the HUD, camera behavior, or GPU profile on an installed system.

## Verify before extraction

Download these three assets into the same directory:

- `CA-AutoConfig-Desktop-v0.2.6-alpha.3-win-x64.zip`
- `CA-AutoConfig-Desktop-v0.2.6-alpha.3-win-x64.sha256`
- `Verify-DesktopPackage.ps1`

Then run:

```powershell
.\Verify-DesktopPackage.ps1 -PackagePath .\CA-AutoConfig-Desktop-v0.2.6-alpha.3-win-x64.zip -ExpectedVersion 0.2.6-alpha.3
```

The verifier performs no extraction, execution, network request, elevation, or hardware write. It requires an exact checksum filename and SHA-256 match, rejects absolute/traversal/control-character paths, case-insensitive duplicate entries, symbolic links, and excessive uncompressed size, and confirms the install-critical files plus the package's declared version.

## Verification completed

- Nine deterministic success/failure cases passed in PowerShell 7 and Windows PowerShell 5.1.
- The previously published `v0.2.6-alpha.2` ZIP verified as 45 files and 280,743,571 uncompressed bytes at its published SHA-256 without extraction.
- The packaged desktop smoke path remains hardware-write-free.

The binaries remain unsigned. The standalone verifier improves corruption and archive-safety checks, but it is not a substitute for future code signing, CI provenance, or a clean-machine installation record.
