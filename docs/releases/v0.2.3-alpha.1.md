# CA AutoConfig v0.2.3-alpha.1

This alpha completes the first three workload adapters with a privacy-safe ComfyUI image-efficiency path and a schema that does not mislabel image throughput as tokens.

## What changed

- Added schema-v2 `workUnitsPerSecond` and `workUnit` fields plus unit-aware work/J reporting; schema-v1 token runs remain supported.
- Added `benchmark/Invoke-ComfyUIPowerRun.ps1` for an explicit API-format workflow and local ComfyUI endpoint.
- Requires an empty queue, one warm-up, a distinct measured seed, terminal success, the declared image count, and a non-cached nominated seed node.
- Measures declared images over the client-observed submission-to-terminal window while sampling selected NVIDIA GPUs.
- Uses loopback by default, disables redirects, and requires `-AllowRemoteEndpoint` before sending a workflow elsewhere.
- Never fetches or deletes generated files and never exports the workflow, prompt text, history payload, output metadata, endpoint, prompt ID, paths, or seed values.
- Deliberately avoids the global interrupt/free/history mutation routes, including on timeout.
- Disabled HTTP redirects in the Ollama adapter as the same loopback-boundary hardening.
- Added eight deterministic ComfyUI tests and expanded schema/report coverage to 19 tests in both PowerShell runtimes.
- Fixed the Markdown observation formatter so leader profile and efficiency values render correctly, with a regression assertion on the complete sentence.

## Install

Download `CA-AutoConfig-Desktop-v0.2.3-alpha.1-win-x64.zip` and its `.sha256` file, verify the checksum, extract it, and run:

```powershell
.\Install-DesktopApp.ps1
```

The installer remains least privilege and HUD-only. Workload adapters are optional scripts and run only when invoked explicitly.

## Try the adapter

Start ComfyUI yourself, export a fixed workflow in API format, and follow [`benchmark/POWER_CURVE_METHOD.md`](../../benchmark/POWER_CURVE_METHOD.md). Use a workflow whose terminal history contains the exact declared image count.

## Verification

- The 19 schema/report tests, nine Ollama tests, nine llama-bench tests, and eight ComfyUI tests pass in Windows PowerShell and PowerShell 7.
- The ComfyUI integration fixture exercises loopback submission, warm-up/measurement seed separation, concurrent telemetry, exact output count, execution failure, and privacy omission without loading a model or image.
- No ComfyUI listener was present on ports 8188/8189 on the maintainer system, so this release does not claim a real diffusion power curve.
- Both live RTX 3090 cards remained at the approved 280 W / 1695 MHz after verification.
- Release ZIP: 74,456,948 bytes; SHA-256 `b41e6c40acc234a67a284105319022bf080339b9bd6ec9904e7de271c5f3c313`.

The adapter reports client-window image throughput, not internal sampler-node timing. A real public curve still requires fixed workflow details, repeated interleaved runs, raw anonymized exports, and retained failures.
