# CA AutoConfig v0.2.1-alpha.2

This corrective alpha makes NVIDIA telemetry failure states deterministic and aligns the executable's internal version metadata with the public `v0.2.1` release line.

## What changed

- NVIDIA telemetry now passes through an injectable internal source boundary; production uses `nvidia-smi`, while tests use a recorded source with no process or hardware access.
- Eight deterministic cases cover valid, missing, timed-out, failed, empty, partially malformed, fully malformed, and explicit-`N/A` telemetry.
- Missing GPU load, VRAM, watts, and temperature render as unknown instead of plausible zero readings.
- Empty or malformed output leaves the GPU-limit indicator red with a specific diagnostic.
- Product version is `0.2.1-alpha.2`, assembly version is `0.2.1.0`, and file version is `0.2.1.2`.
- The optional read-only power-curve lab from alpha.1 remains included in the ZIP.

## Install

Download `CA-AutoConfig-Desktop-v0.2.1-alpha.2-win-x64.zip` and the matching `.sha256` file, verify the checksum, extract it, and run:

```powershell
.\Install-DesktopApp.ps1
```

The installer remains least privilege and HUD-only by default. It does not install camera monitoring or apply GPU settings.
