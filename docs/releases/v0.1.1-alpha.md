# CA AutoConfig v0.1.1-alpha

This maintenance alpha fixes HUD clipping on mixed-DPI monitor layouts. The UI thread now enters per-monitor-v2 DPI awareness before WinForms creates the overlay, so the form bounds and painted content use the same target-monitor coordinate system.

It includes the complete `v0.1.0-alpha` interactive HUD foundation: monitor selection, persistent dragging, configurable lock shortcut, live NVIDIA power/temperature/load telemetry, current-boot profile verification, and a conservative read-only power starting point.

## Try it

```powershell
.\Install-SystemOverlay.ps1
.\tests\SystemOverlay.Smoke.Tests.ps1
```

The release ZIP is generated directly from the tagged Git commit and is accompanied by a SHA-256 checksum. Advisor values remain benchmark candidates and are never applied automatically.
