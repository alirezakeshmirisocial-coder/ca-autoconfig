# CA AutoConfig v0.2.5-alpha.1

This alpha adds a fail-closed idle-power gate for persistent graphics-clock candidates. A workload-efficient clock limit cannot advance toward a recommendation if it materially increases idle board power—or if the paired evidence is missing, busy, mixed, failed, or synthetic.

## What changed

- Added `benchmark/idle-schema-v1.json`, a separate anonymized contract for vendor-auto baseline and persistent-lock candidate runs.
- Added `Record-IdlePowerRun.ps1`, a query-only NVIDIA recorder with explicit condition, clock policy, settling window, sample window, and repetition metadata.
- Added `New-IdlePowerGateReport.ps1` and `IdlePower.psm1` for deterministic aggregate and per-GPU comparisons.
- Added paired dual-3090 fixtures and 12 fail-closed tests covering regression, insufficient repetitions, failed runs, missing telemetry, a busy desktop, mixed driver/hardware/profile evidence, duplicate repetition numbers, privacy, and non-authorization by fixtures.
- Expanded privacy-field rejection to common identifier variants such as `machineName`, `computerName`, and `gpuUuid`.
- Kept idle evidence isolated from workload evidence; Power Curve dry-run now names its workload fixtures explicitly.

## Default gate

The default policy requires at least three unique runs per condition, at least 30 seconds of complete telemetry per run, mean utilization no higher than 5%, and p95 utilization no higher than 15%. Combined idle power must stay within both 5 W and 10% of baseline; each GPU must stay within both 3 W and 15%. Exceeding any one bound blocks progression.

A live pass exposes only `CanProceedPastIdleGate`. It does not recommend or apply a profile. Workload alignment, failures, clock stability, temperature, privilege isolation, explicit confirmation, and verified rollback remain separate requirements.

## Install

Download `CA-AutoConfig-Desktop-v0.2.5-alpha.1-win-x64.zip` and its `.sha256` file, verify the checksum, extract it, and run:

```powershell
.\Install-DesktopApp.ps1
```

The installer preserves a valid existing display selection across upgrades.

## Verification

- 28 Power Curve schema/report/card tests, 12 idle-gate tests, nine Ollama tests, nine llama.cpp tests, and eight ComfyUI tests pass in both Windows PowerShell 5.1 and PowerShell 7.
- Both idle fixture files validate against `idle-schema-v1.json`.
- The fixture report performs no hardware reads or writes; the live recorder contains query-only NVIDIA operations and reports `HardwareWrites = false`.
- The self-contained desktop smoke test verifies the packaged app and display-preserving installer path.

## Evidence boundary

This release contains no real idle comparison, no real workload curve, no whole-system energy measurement, and no universal GPU limit. Synthetic evidence always returns `FIXTURE`, never `PASS`. Read [the idle gate rationale](https://github.com/alirezakeshmirisocial-coder/ca-autoconfig/blob/main/docs/research/IDLE_POWER_REGRESSION.md) and publish exact anonymized inputs with any result.
