# CA AutoConfig v0.2.4-alpha.1

This alpha turns a validated local-AI power-curve dataset into a deterministic, shareable SVG without weakening the evidence boundary.

## What changed

- Added `benchmark/New-PowerCurveCard.ps1` for 1200×675 SVG cards generated from the same privacy-checked rows as the Markdown report.
- Requires at least two comparable profiles with one exact workload fingerprint and one source class; mixed workloads or mixed live/fixture data fail closed.
- Supports schema-v1 token throughput and schema-v2 work-unit throughput without relabeling images as tokens.
- Keeps failed and incomplete repetitions visible in card counts instead of silently dropping them.
- Uses permanent evidence grades: **FIXTURE / NOT HARDWARE EVIDENCE**, **DRAFT / INSUFFICIENT REPETITIONS**, or **MEASURED / LOCAL HARDWARE**.
- Gives fixture, draft, and measured leaders different copy so synthetic data cannot be presented as a hardware result.
- Adds a visible provenance footer requiring the exact anonymized raw JSON and method, plus accessible SVG title/description metadata with axes and per-profile values.
- Adds a deterministic synthetic preview to the README. It is explicitly pipeline evidence, not a real RTX 3090 result.
- Fixes the packaged installer's default executable-path resolution under Windows PowerShell 5.1 and preserves the currently selected attached display across upgrades; an explicit display target is validated before installation.

## Install

Download `CA-AutoConfig-Desktop-v0.2.4-alpha.1-win-x64.zip` and its `.sha256` file, verify the checksum, extract it, and run:

```powershell
.\Install-DesktopApp.ps1
```

The installer runs the HUD as the standard user at Logon and SessionUnlock. It does not install the optional camera experiment or apply GPU settings. The ZIP remains unsigned while signing and clean-machine upgrade coverage are open release gates.

## Try the card safely

The synthetic dry run reads only repository fixtures and performs no GPU query or write:

```powershell
.\benchmark\New-PowerCurveCard.ps1 -DryRun -OutputPath .\artifacts\fixture-power-curve.svg
```

For a real curve, retain at least three interleaved repetitions per profile, including failures, and publish the exact anonymized run JSON plus [`benchmark/POWER_CURVE_METHOD.md`](../../benchmark/POWER_CURVE_METHOD.md) with the uncropped card.

## Verification

- 25 deterministic schema/report/card tests pass in Windows PowerShell 5.1 and PowerShell 7.
- The generated fixture SVG is byte-identical across both runtimes and parses as valid XML.
- Nine Ollama, nine llama.cpp, and eight ComfyUI fixture-adapter tests remain part of the full benchmark suite in both runtimes.
- The card path performs no GPU hardware write; the fixture suite performs no GPU hardware read.
- Visual finish review passed after fixture-safe wording, non-overlapping labels, explicit provenance, and complete accessible metadata were verified.

No real workload power curve, external hardware reproduction, or universal GPU limit is claimed by this release.
