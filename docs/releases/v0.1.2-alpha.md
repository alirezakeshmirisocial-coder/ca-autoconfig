# CA AutoConfig v0.1.2-alpha

This alpha hardens the boundary between the unprivileged HUD and the optional elevated NVIDIA helper.

## What changed

- The combined installer now installs only the HUD and control shortcut by default. Camera monitoring and GPU mutation are separate opt-ins.
- GPU installation requires an explicit comma-separated GPU index list, graphics-clock ceiling, power limit, and `-AcceptHardwareRisk` acknowledgement.
- Every requested GPU and vendor-reported power range is preflighted before the first setting changes.
- A failed apply records a best-effort rollback: it resets clock locks created by the run and restores the prior power limit for cards it changed.
- The SYSTEM scheduled task source lives in an administrator-owned, non-reparse-point directory that normal users can read but cannot modify.
- A new smoke test checks these safety invariants without changing GPU settings.
- The adaptive-cooling lab documents its simulation-only thermal model and passes 35 synthetic safety scenarios; it still has no hardware-write path.

## Safe HUD-only install

```powershell
.\Install-SystemOverlay.ps1
.\tests\SystemOverlay.Smoke.Tests.ps1
```

## Optional maintainer-machine GPU profile

The following values are an example for the maintainer's exact boards, not a general recommendation:

```powershell
.\Install-GpuLimits.ps1 -GpuIndexList '0,1' -MaxGraphicsClockMHz 1700 -PowerLimitWatts 280 -AcceptHardwareRisk
.\tests\GpuLimits.Safety.Tests.ps1
```

Review `nvidia-smi` and the board manufacturer's limits before choosing values. The release ZIP is generated from the tagged commit and includes a SHA-256 checksum.
